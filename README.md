▎Clicker

Clicker — fullstack pet-project: мобильная clicker-игра для Android с клиентом на Expo / React Native / TypeScript и сервером на Node.js / Express / MongoDB.

Проект сделан как самостоятельная fullstack-разработка: от мобильного интерфейса и игровой логики до API, базы данных, тестов и продакшен-деплоя.

▎Игровая часть

• основная clicker-механика
• магазин улучшений
• лидерборд
• достижения
• система престижа
• страница умений
• пассивный доход / офлайн-прогресс

▎Клиент

• мобильное приложение на Expo и React Native
• кодовая база на TypeScript
• регистрация и авторизация
• работа с backend API
• безопасное хранение токенов через SecureStore

▎Сервер

• REST API на Express
• база данных MongoDB через Mongoose
• аутентификация на JWT
• хеширование паролей через bcrypt
• middleware для защиты приватных маршрутов
• серверная обработка части игровой логики
• тесты на Jest

▎Архитектура

Проект разделен на две части, расположенные рядом в корне репозитория:

• /frontend — мобильное приложение
• /backend — сервер, API и игровая логика

Клиент взаимодействует с сервером по API.  
Авторизация построена на JWT: после входа токен используется для доступа к защищенным маршрутам.  
Часть логики вынесена на backend, чтобы снизить зависимость от клиентской стороны и усложнить читинг.

▎Запуск проекта локально

▎1. Клонирование репозитория

Bash

git clone <repo-url>
cd Clicker

▎2. Запуск backend

```Bash

cd backend
node server
```

Переменные окружения для сервера описаны в файле .env.examples внутри папки backend.

▎3. Запуск frontend

```Bash

cd frontend
npm install
npm run start
```

Переменные окружения для клиента описаны в файле .env.examples внутри папки frontend.

▎Переменные окружения

Для клиента и сервера используются разные .env-файлы.

Примеры и описание переменных уже подготовлены в:
• backend/.env.examples
• frontend/.env.examples

Перед локальным запуском нужно создать свои .env на основе этих шаблонов.

▎Тестирование

На backend используются тесты на Jest.

Покрыты ключевые сценарии, связанные с click-механикой:
• валидация кликов
• защита от читов
• проверка корректности серверной обработки действий игрока

Запуск тестов:

```Bash

cd backend
npm test
```

▎Деплой

Backend развернут в продакшене на Railway.

Android-сборка проекта публикуется в разделе GitHub Releases, где можно скачать готовый APK.

▎Статус

Проект рабочий и разворачивается как отдельные frontend и backend части.  
Backend используется в продакшен-окружении, а актуальная Android-сборка доступна через Releases.
